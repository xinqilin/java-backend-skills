@Transactional is a proxy@Transactional 是一層 proxy

Spring wraps your bean in a doorman. Only calls that walk through the door get a transaction. Spring 會在你的 bean 外面包一個門衛。只有從門口走進來的呼叫，才會開交易。

Calling yourself skips the door自己呼叫自己，就繞過了門衛

Fix: move place() to another bean, or use TransactionTemplate for the inner unit of work. 解法：把 place() 移到另一個 bean，或用 TransactionTemplate 包住裡面那段工作。

Checked exceptions commitChecked exception 會 commit

Use @Transactional(rollbackFor = Exception.class) when a checked exception should undo the work. 如果 checked exception 也該撤銷這次的工作，請用 @Transactional(rollbackFor = Exception.class)。

REQUIRES_NEW holds two connectionsREQUIRES_NEW 會同時拿兩條連線

Spring's own docs say: only use REQUIRES_NEW when the pool exceeds the number of concurrent threads by at least one. Spring 官方文件說：只有在 pool 大小至少比同時執行的 thread 數多 1 的時候，才使用 REQUIRES_NEW。

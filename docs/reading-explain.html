Reading EXPLAIN看懂 EXPLAIN

A plan is the database's to-do list for your query. EXPLAIN shows the guess; EXPLAIN ANALYZE runs it and shows what really happened. 執行計畫就是資料庫處理這個查詢的待辦清單。EXPLAIN 給你它的猜測；EXPLAIN ANALYZE 會真的執行，告訴你實際發生了什麼。

Guess vs. reality猜測與實際

A big gap means the planner was working with wrong statistics. Refresh them first (ANALYZE TABLE t in MySQL, ANALYZE t in PostgreSQL), then decide whether an index is missing. 差距很大，代表規劃器用的統計資料是錯的。先更新統計（MySQL 用 ANALYZE TABLE t，PostgreSQL 用 ANALYZE t），再判斷是不是少了 index。

What to look for該看哪些地方

ANALYZE really runs itANALYZE 會真的執行

BEGIN;
EXPLAIN (ANALYZE, BUFFERS) UPDATE orders SET status = 'PAID' WHERE id = 42;
ROLLBACK;   -- PostgreSQL: keep your data unchanged

For an UPDATE or DELETE, wrap it in a transaction and roll back. And test on production-sized data: plans on tiny tables lie. 對 UPDATE 或 DELETE 要包在交易裡再 rollback。也要在接近正式環境大小的資料上測：小表的執行計畫不準。

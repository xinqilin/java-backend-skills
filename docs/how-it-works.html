How the plugin worksplugin 怎麼運作

Commands you type, helpers that do the work, and knowledge cards the helpers read before they start. 你輸入的指令、實際做事的小幫手，以及小幫手開工前先讀的知識卡。

1. A command calls a helper1. 指令會叫一個小幫手

2. First, it reads your project2. 先讀你的專案設定

3. Which command goes where3. 哪個指令交給誰

Reviewers never change your files. Writing tests and designing happen in your own conversation, so you see every edit and can answer questions. 審查類的小幫手不會改你的檔案。寫測試和做設計在你自己的對話裡進行，每次修改你都看得到，也能回答它的問題。

4. Every fact has a source4. 每個說法都有出處

Each knowledge card ends with links to the MySQL, PostgreSQL, Hibernate, or Spring documentation it was checked against. 每張知識卡的最後，都附上查證時用的 MySQL、PostgreSQL、Hibernate 或 Spring 官方文件連結。

Replica lagReplica 延遲

Read replicas copy the primary a little later. "A little" is usually milliseconds, and sometimes much more. Read replica 會晚一點才複製到主資料庫的內容。「晚一點」通常是幾毫秒，有時候會久得多。

Three rules三條規則

In Spring, LazyConnectionDataSourceProxy can send read-only transactions to a separate replica DataSource (Spring Framework 6.1.2+). Mark only the reads that can tolerate lag as @Transactional(readOnly = true). 在 Spring 裡，LazyConnectionDataSourceProxy 可以把唯讀交易導到另一個 replica DataSource（Spring Framework 6.1.2 以上）。只有能容忍延遲的讀取，才標成 @Transactional(readOnly = true)。

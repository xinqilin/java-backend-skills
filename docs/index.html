The bugs that hurt Java backends hide where the code meets the database. These pages explain those ideas with pictures; the plugin teaches Claude the same ideas, checked against official docs. Java 後端最痛的 bug，藏在程式碼和資料庫交會的地方。這些頁面用圖解釋這些觀念；plugin 則把同樣的觀念教給 Claude，內容都對照過官方文件。

Install in Claude Code: 在 Claude Code 裡安裝： 

/plugin marketplace add xinqilin/claude-dev-toolkit-marketplace
/plugin install java-backend@xinqilin
